# 🎁 Telegram Wishlist Bot

Бот для управления списками желаний (wishlist) с возможностью делиться с друзьями.

## Возможности

- ✅ Добавление хотелок (текст, фото, видео)
- ✅ Отметка выполнено/не выполнено
- 🗑️ Удаление хотелок
- 👥 Система друзей
- 🔗 Ссылки-приглашения

## Развертывание на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app) через GitHub

2. Создайте новый проект:
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Выберите этот репозиторий

3. Добавьте переменную окружения:
   - Откройте Variables
   - Добавьте: `TELEGRAM_BOT_TOKEN` = `ваш_токен_от_BotFather`

4. Deploy автоматически запустится!

## Локальный запуск

```bash
pip install -r requirements.txt
python3 bot.py
```

## Команды бота

- `/start` - начало работы
- `/list` - ваш список хотелок
- `/share` - ссылка для друзей
- `/friends` - списки друзей
- `/help` - справка
